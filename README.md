## ✨ 为什么是它

- **一个文件就是全部**
  卡片、挖空题、样式、逻辑全在 `index.html`，离线可运行，微信里点开就能用。

- **科学复习**
  艾宾浩斯间隔重复：1 / 2 / 4 / 7 / 15 / 30 / 60 天滚动。答对升一档，答错次日重来；连对 4 次且间隔 ≥15 天才算「已掌握」。

- **进度只属于你**
  无账号、无后端、无埋点，全部存在浏览器本机，可随时导出 JSON 备份。

- **正文不是一坨字**
  列举内容自动分段排版：`（1）（2）…`、`①②…`、`1. 2. …`、`一、二、…` 识别成小方块编号 + 悬挂缩进；年份、温度这类正文数字不会被误拆。

## 🧭 五个标签页

### 📖 常识

知识点卡片，两种模式一键切换：

| 模式 | 玩法 |
|---|---|
| **记忆** | 知识点直接铺开阅读，读完自评「忘了 / 模糊 / 记住了」 |
| **背诵** | 考点挖空自测，先回忆再点空格揭晓答案 |

- 顶部按 16 个板块筛选，只刷某一类
- 「打乱 / 顺序」一键重排剩余队列，已答进度不受影响
- 卡片右上角「✎ 纠错」随时给内容记一笔

### 🎴 成语

翻卡模式：正面成语 + 拼音，点击翻面看释义。
左滑记住 · 右滑忘了 · 上滑收藏，键盘 `1` / `2` / `3` 同样可评分。

### ⚡ 测验

四选一快测，结算页直接给复盘：

- 题量 10–100，范围可选全部 / 单板块 / **错题本** / 已收藏
- 乱序或按顺序出题
- 结算：用时、正确率、每题均速、错题回顾
- 「只练这 N 道错题」一键专练

### 📚 卡片库

2555 张卡全量浏览：搜索框 + 可折叠筛选面板（16 个板块 × 学习状态），点外部自动收起。

### 📊 数据

看板一屏看全：刷题时间、学习时长柱状图（日 / 周 / 月）、正确率（总体 + 分板块）、学习日历热力图、学习量统计（学过 / 背过 / 记住 / 忘了 / 模糊 / 刷过）。

## 📱 移动端与微信

单文件、零外链、零网络请求，微信内置浏览器（iOS WKWebView / Android X5·XWeb）**直接可用**：

- 视口高度不依赖 `dvh`，用 JS 写入 `px` 兜底（部分 XWeb 内核不认 `dvh`）
- 禁长按菜单、电话号码自动识别、点选高亮；输入框字号 ≥16px 防聚焦放大
- Android 微信下关闭毛玻璃（X5 的 `backdrop-filter` 兼容性差），改实色背景
- 老内核没有 `PointerEvent` 时自动用 touch 事件合成，翻卡与滑动评分照常
- 翻卡正反面互斥双保险：`backface-visibility` + 翻转过半切换 `visibility`，杜绝 iOS / XWeb 镜像透出

## 🗂 目录结构

```
.
├── index.html            # 构建产物：单文件应用（含全部卡片与挖空题）
├── build.sh              # 一键重建（切卡 → 合并 → 挖空 → 渲染 → 同步 dist）
├── test.sh               # 一键自检（165 项断言 + 无头 Chrome）
├── templates/app.html    # 应用模板（HTML + CSS + JS）
├── data/
│   ├── cards.json        # 卡片主库（构建产物，同时在版本库中充当输入）
│   ├── quiz.json         # 挖空题（存偏移量，前端按需切片还原）
│   ├── knowledge.json    # 从教材切出的常识卡
│   ├── supplement.json   # 人工补充的成语与政治理论速记
│   ├── idioms_manual.json# 教材成语 1000 条
│   └── overrides.json    # 人工校正表（按 front 匹配）
└── scripts/
    ├── build_knowledge.py  # PDF 文本 → 常识卡（分节、过滤、清洗）
    ├── build_supplement.py # 补充卡片
    ├── build_all.py        # 合并 → cards.json + 导出 CSV / Markdown
    ├── gen_quiz.py         # 生成挖空题（分级兜底，覆盖率 100%）
    ├── render.py           # 注入数据 → index.html
    └── selftest.js         # 生成自检页面
```

`raw/`（教材原文）、`dist/`（发布副本）、`outputs/`（导出文件）均不纳入版本库。

## 🔒 隐私

- 无账号、无后端、无埋点，所有进度存浏览器 `localStorage`
- 换设备：旧设备「导出进度」→ 新设备「导入进度」
- 清空浏览器数据会丢进度，建议定期导出备份

## 📄 数据来源与版权

卡片内容整理自公开出版的个人备考资料（成语释义、常识考点）。**仅限个人学习使用，请勿商用或公开传播原始内容。** 教材 PDF 原文未提交至本仓库。

## 🧭 已知限制

- 进度只存本机，无自动多端同步
- 约 5% 的常识卡由 PDF 规则切分而来，措辞可能偏生硬（遇到可跳过，或提 issue 后用 `overrides.json` 修正）
- iOS Safari 左边缘右滑会触发浏览器返回，与「右滑忘了」有冲突，从卡片中部开始滑动可避免
- `file://` 下无法注册 Service Worker，本地版不能做离线 PWA（线上部署版可以）
