# 上岸常识刷刷刷

面向个人学习者的常识 / 成语知识卡工具。单文件网页应用，双击即用，进度存在本机，不依赖任何后端。

> 全部卡片与挖空题打包在 `index.html` 里（约 1.0 MB），离线可运行。

---

## 功能

底部五个标签：

| 标签 | 说明 |
|---|---|
| **常识** | 常识类知识点两种模式：**记忆**（直接铺开阅读，读完自评「忘了 / 模糊 / 记住了」）与**背诵**（考点挖空自测）；顶部可按板块筛选、可「打乱 / 顺序」重排剩余队列；卡片右上角「✎ 纠错」可给内容记一笔待改 |
| **成语** | 翻卡模式：正面成语 + 拼音，点击翻面看释义；左滑记住、右滑忘了、上滑收藏 |

正文里的列举（`（1）（2）…`、`①②…`、`1. 2. …`、`一、二、…`）会自动分段排版：编号做成小方块标签、条目悬挂缩进，记忆与背诵两种模式同样生效。判定很保守——只有编号连续递增、至少两条、且不是「第1.节」这类章节引用时才分段，因此正文里的数字（年份、温度、比例）不会被误拆。
| **测验** | 四选一随机测：题量 10–100、范围可选全部 / 单个板块 / **错题本** / 已收藏、可乱序或按顺序，答完给用时 / 正确率 / 每题均速 / 错题回顾，并可「只练这 N 道错题」 |
| **卡片库** | 2555 张卡全量浏览：搜索栏下方「筛选」下拉把 16 个板块和学习状态做成可折叠面板，点外部自动收起，也可一键重置 |
| **数据** | 刷题时间、学习时长（日 / 周 / 月柱状图）、正确率（总体 + 日周月 + 各板块）、学习日历热力图 |

其他：

- **每日目标**：默认 60 题，进度条常驻常识页顶部；达标当天放一次礼花（可在设置里改或关闭）
- **错题本**：答错且未掌握的卡自动进入，测验里可直接专练；答对到「已掌握」后自动移出
- 右上角圆环显示当前板块完成百分比，数字严严整整落在圆心；点圆环弹出明细（已完成 N / M 张），指针光标 + 悬停变色，命中区域就是圆环本身
- 六套配色主题（宣纸 / 朱砂 / 青苔 / 夜航 / 橘子汽水 / 樱花），跟随系统或手动切换
- 完成任务后触发礼花动画 + 随机鼓励语（尊重 `prefers-reduced-motion`）；祝福卡右上角有「×」可立即收起，也支持 `Esc`
- 键盘操作：空格翻面、`1` / `2` / `3` 评分、`S` 跳过
- 进度可导出 / 导入 JSON，换设备不丢
- **纠错闭环**：常识卡「✎ 纠错」→ 数据页列表（可单条删除）→「校正草稿」一键整理成 `overrides.json` 格式（附当前正文与说明），发回来即可改卡

## 移动端与微信内置浏览器

单文件、零外链、零网络请求，因此微信内置浏览器（iOS 的 WKWebView / Android 的 X5·XWeb）里不需要任何额外配置即可直接使用：

- 视口高度不依赖 `dvh`，用 JS 写一份 `px` 兜底（部分 XWeb 内核不认 `dvh`）
- 禁掉长按弹菜单、自动识别电话号码、点选高亮，输入框字号 ≥16px 避免聚焦时页面被放大
- Android 微信下关闭顶栏毛玻璃（X5 的 `backdrop-filter` 兼容性差），改为实色背景
- 老内核没有 `PointerEvent` 时，自动用 touch 事件合成同结构事件，翻卡与滑动评分仍然可用
- 翻卡正反面互斥：`backface-visibility` 之外再加一层「翻转过半切换可见性」兜底，避免 iOS / XWeb 把正面以镜像透出

## 复习算法

答对升一档，间隔按 **1 / 2 / 4 / 7 / 15 / 30 / 60** 天滚动；答错退回第 0 档，次日重来；连续答对 4 次且间隔 ≥15 天才标记为「已掌握」。

每日新卡与复习上限在设置里调（默认 **30 张新卡 / 200 张复习**，两个板块合计分配，一方不够时余量让给另一方）。

每日目标的进度口径与正确率一致：只算「记住了 / 忘了」和测验对错，「模糊」不计入题数（只计入学习时长）。

## 目录结构

```
.
├── index.html            # 构建产物：单文件应用（含全部卡片与挖空题）
├── build.sh              # 一键重建（切卡 → 合并 → 挖空 → 渲染 → 同步 dist）
├── test.sh               # 一键自检（159 项断言 + 无头 Chrome）
├── templates/app.html    # 应用模板（HTML + CSS + JS）
├── data/
│   ├── cards.json        # 卡片主库（构建产物，同时在版本库中充当输入）
│   ├── quiz.json         # 挖空题（存偏移量，前端按需切片还原）
│   ├── knowledge.json    # 从教材切出的常识卡
│   ├── supplement.json   # 人工补充的成语与政治理论速记
│   ├── idioms_manual.json# 教材成语 1000 条
│   └── overrides.json    # 人工校正表（按 front 匹配）
└── scripts/
    ├── build_knowledge.py  # PDF 文本 → 常识卡（分节、过滤、清洗）
    ├── build_supplement.py # 补充卡片
    ├── build_all.py        # 合并 → cards.json + 导出 CSV / Markdown
    ├── gen_quiz.py         # 生成挖空题（分级兜底，覆盖率 100%）
    ├── render.py           # 注入数据 → index.html
    └── selftest.js         # 生成自检页面
```

`raw/`（教材原文）、`dist/`（发布副本）、`outputs/`（导出文件）均不纳入版本库。

## 构建

```bash
./build.sh
```

依赖：Python 3 + `pypdf`。原始 PDF 需放在 `scripts/build_knowledge.py` 顶部配置的目录中；仓库不包含教材原文，仅提交已切好的 `data/*.json`。

改卡片内容请改 `data/overrides.json`（按 `front` 匹配），不要直接改 `cards.json`，重新构建会被覆盖。

## 自检

```bash
./test.sh
```

覆盖 165 项：启动、常识记忆 / 背诵（含板块筛选、打乱 / 顺序、去重）、列举分段（含混排 / 重启编号）、翻卡手势与正反面互斥、测验、错题本专练、每日目标、纠错记录、学习量统计、卡片库筛选 / 折叠下拉 / 搜索、数据看板、设置、导入导出、礼花触发、计时逻辑、路由。有失败项返回非 0。

## 隐私

- 无账号、无后端、无埋点。所有进度存在浏览器 `localStorage`
- 换设备需手动「导出进度」→ 新设备「导入进度」
- 清空浏览器数据会丢失进度，建议定期导出备份

## 数据来源与版权

卡片内容整理自公开出版的个人备考资料（成语释义、常识考点）。**仅限个人学习使用，请勿商用或公开传播原始内容。** 仓库中的 PDF 原文未提交。

## 已知限制

- 进度只存本机，无自动多端同步
- 约 5% 的常识卡由 PDF 规则切分而来，措辞可能偏生硬（遇到可跳过，或提 issue 后用 `overrides.json` 修正）
- iOS Safari 的左边缘右滑会触发浏览器返回，与「右滑忘了」有冲突，从卡片中部开始滑动可避免
- `file://` 下无法注册 Service Worker，因此本地版不能做成离线 PWA（线上版可以）
